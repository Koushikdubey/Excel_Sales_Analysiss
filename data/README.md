# Retail Sales Dataset

## Overview
This folder contains the dataset used for the Retail Sales Analysis Dashboard project developed using Microsoft Excel.

## Dataset Details
- **File:** `retail_sales_dataset.csv`
- **Format:** CSV
- **Records:** Approximately 190,757 data rows
- **Fields:** 19 columns
- **Purpose:** Retail sales analysis, revenue tracking, product performance analysis, and trend identification.

## Data Preparation
The dataset was prepared for analysis and includes fields used to evaluate sales performance across products, brands, categories, regions, sales channels, and promotions.

## Usage
The dataset supports the Excel dashboard and related analysis, including:
- Monthly and yearly sales trends
- Revenue and units sold
- Category and brand performance
- Regional and sales-channel analysis
- Promotional performance
- Top-performing SKUs
